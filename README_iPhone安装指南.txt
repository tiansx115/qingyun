《这届修仙不太对》iPhone 离线桌面安装指南
========================================
1. 解压本压缩包，里面包含：
   - index.html（游戏本体，内嵌全部电影写实美术、音效与引擎）
   - manifest.json（iPhone 桌面应用配置，默认全屏横屏）
   - sw.js（Service Worker 离线缓存脚本）
   - icon-192.png / icon-512.png（iPhone 桌面图标）

2. 如何装到苹果手机桌面并离线游玩：
   - 将解压后的整个文件夹上传到任意免费 HTTPS 静态托管（如 GitHub Pages、Cloudflare Pages 或 Vercel）。
   - 用 iPhone 自带的 **Safari** 浏览器打开该网址。
   - 点击底部工具栏的「分享」图标（方框带向上箭头）→ 选择「添加到主屏幕」。
   - 完成后桌面会出现《这届修仙不太对》图标，点开即为全屏横屏游戏，且此后**彻底断网也能正常游玩与本地存档**。
